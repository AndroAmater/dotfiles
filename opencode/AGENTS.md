## Memory

Long-term memory lives in the Obsidian vault at `~/Documents/AI Memory`.

- At the start of non-trivial work, load the `memory-recall` skill.
- When you learn something worth keeping across sessions (user corrections, confirmed approaches, project context, external references), load the `memory-save` skill.
- Never write memory anywhere else (no `~/.claude/projects/*/memory`, no `MEMORY.md`).
